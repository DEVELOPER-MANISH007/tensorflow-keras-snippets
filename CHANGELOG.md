# Changelog

## 0.1.0

- Introduced the distinct TensorFlow Keras Pro Snippets extension identity.

- Expanded the library to 163 Python snippets across seven registered categories.
- Added dataset, computer vision, core Keras training, transfer learning, NLP, time-series, serialization, diagnostics, and utility workflows.
- Added a local validator for snippet JSON, schema, registration, prefix uniqueness, and expanded Python syntax.
- Documented local development, API compatibility assumptions, and extension limitations.
